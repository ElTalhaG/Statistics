# Lab 7 - Chapter 4 Exercises

The runnable simulation and bootstrap work for Exercises 4.1, 4.3, 4.4, and 4.5 is in [lab_7_simulations.py](<lab_7_simulations.py>). From this folder, run:

    python3 lab_7_simulations.py

The script prints the seeded simulation results and saves the Exercise 4.1 histogram beside itself. It uses NumPy, SciPy, and Matplotlib. If pandas is installed, Exercise 4.1 stores component lifetimes in a DataFrame; otherwise it uses a NumPy fallback.

Exercise 4.2 is calculated from the ordered bootstrap means supplied in the [Chapter 4 solutions PDF](<statistics_exercises_ch4_solution.pdf>).

The full step-by-step explanations, formulas, interpretations, and results are in the [Obsidian Lab 7 note](<file:///Users/talha/Documents/Obsidian%20Vault/3.%20SEMESTER/Statistics%2002323/3.%20Lab/Lab%207.md>).
